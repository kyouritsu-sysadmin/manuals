> This is a sample guide for the new library, not an approved company policy.

## Find a document

Choose a division from the navigation or browse the division cards on the library homepage. Within a division, use **Manuals**, **Guides**, **Policies**, or **Forms** to narrow the list.

Search matches document titles, descriptions, division names, and languages. It does not search inside PDF contents.

## Read or download

Open a document to read its web page or flipbook. Use the arrows, page corners, page-number field, or thumbnail panel to navigate. Zoom and fullscreen controls help with detailed reading. Switch to **Standard PDF** for text selection, PDF search, and printing. For PDFs, **Open file** opens the original document in a new tab. **Download** saves a copy for offline use. If your browser cannot show the preview, use either of those links.

## Share a specific document

Copy the URL from your browser while viewing the document. Each document has its own stable address, so colleagues can go directly to it.

## Return to your team

Use the breadcrumbs or the division overview link to return to your division’s resources.

## Change the interface language

Choose **English** or **日本語** from the language menu. This changes the site interface and translated web guides; it does not translate the attached PDF.
